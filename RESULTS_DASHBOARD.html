⚙️ Preprocessing Strategy

For Skewed Features (|skewness| > 0.5):
  1. Apply PowerTransformer (Yeo-Johnson method)
  2. Apply StandardScaler for normalization
For Normal Features (|skewness| ≤ 0.5):
  1. Apply StandardScaler directly
For Categorical Features:
  1. Apply pd.get_dummies (one-hot encoding)
  2. Note: No categorical features in this dataset
